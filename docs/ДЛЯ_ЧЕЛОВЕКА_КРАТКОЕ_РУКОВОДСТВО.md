## Предложенное архитектурное решение

С учётом требований и минимальной сложности предлагаю такой стек:

| Компонент | Решение | Пояснение |
|-----------|---------|-----------|
| Backend | Node.js + TypeScript + Express | Доступен в окружении, простой, удобен для REST API и работы с OpenRouter |
| Frontend | Vite + TypeScript | Лёгкий, быстрый, минимальные зависимости |
| Хранение | Файловое JSON-хранилище (`data/`) | Без отдельного сервера БД, легко посмотреть/отредактировать, достаточно для старта |
| Шаблоны сайтов | Простой шаблонизатор (Handlebars/EJS) | Генерация статичного HTML/CSS/JS для скачивания ZIP-архивом |

## Ключевые принципы

- **Единый источник фактов** - только сохранённая карточка компании. При генерации сайта факты берутся из неё и не меняются.
- **Версионирование** - если изменить карточку и сгенерировать сайт заново, старый сайт останется доступным. Создаётся новая версия.
- **Безопасность** - API-ключ OpenRouter хранится только на сервере. Никогда не попадёт в клиент, экспортируемые файлы, логи.
- **Сайт без "пустышек"** - формы, личный кабинет, загрузка файлов и прочее не будут представлены как работающие.
- **Поддержка языков** - русский и немецкий. Факты не меняются при смене языка.
- **Расширяемость** - архитектура спроектирована под расширение до 8 направлений с общим хранилищем фактов.
